# Система оплати та доставки

## 📦 Нова Пошта API (REAL)

Інтегровано **реальний API Нової Пошти** для довідкової інформації про доставку.

### Функціональність:
- ✅ Пошук міст по назві (автодоповнення)
- ✅ Отримання списку відділень для обраного міста
- ✅ Реальні дані з API Нової Пошти
- ✅ Автоматичне завантаження відділень при виборі міста

### API Endpoints:
- `Address/searchSettlements` - пошук населених пунктів
- `Address/getWarehouses` - отримання відділень
- `Address/getCities` - отримання міст
- `Address/getAreas` - отримання областей

### Використання:
```typescript
// Пошук міст
const cities = await NovaPoshtaService.searchCities('Київ');

// Отримання відділень
const warehouses = await NovaPoshtaService.getWarehouses(cityRef);
```

### Особливості:
- API Key: використовується демонстраційний ключ
- Debounce: пошук активується після 500мс від останнього введення
- Мінімальна довжина запиту: 2 символи
- Ліміт результатів: 20 міст, 100 відділень

## 💳 Stripe Payment (SANDBOX)

Інтегровано **Stripe в тестовому режимі** для симуляції оплати.

### Тестові картки:

#### ✅ Успішна оплата:
```
Номер: 4242 4242 4242 4242
CVV: будь-які 3 цифри (наприклад: 123)
Термін: будь-яка майбутня дата (наприклад: 12/26)
Результат: Успішна оплата
```

#### ❌ Відхилена картка:
```
Номер: 4000 0000 0000 0002
CVV: будь-які 3 цифри
Термін: будь-яка майбутня дата
Результат: Картку відхилено
```

#### 🔒 3D Secure:
```
Номер: 4000 0027 6000 3184
CVV: будь-які 3 цифри
Термін: будь-яка майбутня дата
Результат: Успішна оплата з 3D Secure
```

### Валідація:
- ✅ Перевірка довжини номера картки (16 цифр)
- ✅ Валідація терміну дії (MM/YY)
- ✅ Перевірка CVV (3-4 цифри)
- ✅ Визначення типу картки (Visa, Mastercard, Amex)
- ✅ Форматування номера картки (з пробілами)

### Процес оплати:

1. **Створення Payment Intent** (симуляція)
   ```typescript
   const intent = await StripeService.createPaymentIntent(amount, 'UAH');
   ```

2. **Обробка платежу**
   ```typescript
   const result = await StripeService.processPayment(
     cardNumber, 
     cardExpiry, 
     cardCvc, 
     cardName, 
     amount
   );
   ```

3. **Отримання результату**
   - `success: true` - оплата успішна
   - `success: false` - помилка оплати
   - `transactionId` - ID транзакції
   - `message` - повідомлення про результат

## 🛒 Процес оформлення замовлення

### Крок 1: Кошик
- Перегляд товарів
- Зміна кількості
- Видалення товарів
- Розрахунок загальної вартості

### Крок 2: Доставка (Нова Пошта)
- Введення контактних даних (ПІБ, телефон, email)
- Вибір міста (пошук через API)
- Вибір відділення (автозавантаження)

### Крок 3: Оплата (Stripe)
- Введення даних картки
- Валідація даних
- Обробка платежу
- Створення замовлення

### Крок 4: Успіх
- Генерація номера замовлення
- Збереження замовлення в localStorage
- Очищення кошика
- Відображення деталей замовлення
